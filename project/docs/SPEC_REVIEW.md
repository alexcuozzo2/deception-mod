# Specification basis

The v1.5 handoff, presentation appendix and all-tribe/Centipede v1.6 amendment are
retained in `spec/`. The latest user request is recorded in
`spec/UI_A02_RECRUITMENT_WHEEL.md`: two native recruitment wheels, recognizable
Mimic choices, own unlocked roster, no popup cycling. This is a direct-recruitment
UI change, not a new gameplay exception or alteration of later mechanics.

A Basic-only ordinary roster has Warrior only. Native starting unit unlocks and
special-tribe overrides still count; the user did not revoke v1.6's roster policy.
There is no direct cross-tribe roster grant, super-unit option before Propaganda,
or free genuine research. The existing 26-form prototype coverage is unchanged.

Full release acceptance cases are retained with no fabricated execution results.
The new tests are model/file-level subchecks, not native acceptance passes.
