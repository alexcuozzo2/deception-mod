# M1D source candidate status

The working M1C research, compact technology popup, appearance wheel and native three-star purchases are the user-reported baseline. M1D adds apparent form/HP UI projection, private repeat-selection inspection, explicit Mimic/Back text controls, and scoped native noncombat-readiness access.

M1D is reviewed source, not a built or game-tested mod. See `M1D_REVIEW.md` for file/symbol references, `VALIDATION_M1D.md` for actually observed checks, and `M1D_PLAYTEST.md` for the Mac acceptance steps. The historical M1C documents are preserved in `history/M1C/` and are not the current status.

Actual HP remains 1/1 (10 native stored units). The private portrait is an explicitly labeled placeholder in the local information popup; the battlefield stays apparent. Ordinary command mode remains separate from inspection. Only the recruited initial full-health appearance is reconstructed natively; later apparent wounds require a persistence adapter before those mechanics can be enabled.

Native health coloring, popup/input timing and noncombat action behavior need actual Mac tests. Identity-safe embarkation, Cloaks and the other omitted forms remain open. The prototype's transport guard is retained. Higher technologies, full observer/readiness/AI/replay/multiplayer secrecy and save migration remain unfinished.
