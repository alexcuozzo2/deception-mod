# UI-A65 — Visible Spies (0.3.102)

Alex removes intrinsic Spy invisibility for balance. Spy and Spymaid no longer
have native Hide and moving cannot grant invisibility. Spy/Spymaid appearances
likewise cannot grant Hide to Mimics or other disguised units. Block queued Hide
for a genuine Spy unless it has an eligible Cloak disguise; normal Cloak disguise
rules remain available just as for other units. Actual Cloaks retain concealment
and Infiltrate readiness while wearing a Spy appearance.

Retain cost5, health5, defense1, movement2, attack0, Scout, Subvert and no Dash;
Spymaid retains Swim/Amphibious. Preserve Mimic Dash and all integrated Windows fixes.
Update descriptions. Existing Invisible effects saved under older rules are not
retroactively rewritten; native reveal and existing reveal-on-ability paths clear
them. No new hide may be earned from actual or apparent Spy identity.

Both online peers need the same rebuilt candidate. This source change does not
install a mod or update the historical Windows candidate launcher hash.
